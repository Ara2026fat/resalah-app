# رسالة | Resalah

تطبيق ويب تقدّمي (PWA) لجمعية الدعوة والإرشاد وتوعية الجاليات بالجبيل الصناعية.

## النشر على GitHub Pages
1. ارفع كل الملفات في جذر المستودع (بلا مجلدات).
2. Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Folder: /(root) ← Save.
3. افتح الرابط https://USERNAME.github.io/REPO/ على الجوال أو الحاسوب.

## التحديث
ارفع الملفات الجديدة فوق القديمة، ثم غيّر رقم VERSION في sw.js ليصل التحديث للمستخدمين.
